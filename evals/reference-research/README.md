# Reference-analysis benchmark

`benchmark-index.yaml` contains 24 works sampled evenly across the four curated Tier A studios. `annotations.json` contains eight manually reviewed provisional annotations spanning narrative, composition, and motion fields.

The labels deliberately preserve unknowns. Portfolio copy and thumbnails cannot establish motion or pacing. A record becomes `gold: true` only after two reviewers watch the complete work, add scene timestamps, independently label it, and resolve disagreements. This prevents the benchmark from rewarding confident fabrication.

The evaluator checks coverage, field honesty, provenance, tier diversity, pattern abstraction, and non-copy guidance. It does not reward agreement with a studio's visual style.
