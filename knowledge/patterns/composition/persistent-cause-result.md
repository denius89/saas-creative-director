# Persistent cause/result

- Pattern ID: `PAT-COMP-001`
- Problem: a viewer must connect an action to an outcome without remembering a previous shot.
- Mechanism: keep the triggering object and result region visible simultaneously; animate the state change between them.
- Use for: automation, transfer, transformation, matching, routing.
- Avoid when: the mechanism has many branches that make a single frame unreadable.
- Non-copy rule: reuse the information relationship, not any source's layout, palette, or branded objects.
