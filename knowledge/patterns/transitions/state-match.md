# State-match transition

- Pattern ID: `PAT-TRANS-001`
- Problem: moving from conceptual context into product UI causes cognitive reset.
- Mechanism: align shape, position, or semantic role across the cut so the new state inherits attention.
- Use for: metaphor-to-UI and overview-to-detail transitions.
- Avoid when: the match hides an important change of scale or context.
- Non-copy rule: design a new semantic match from the client's objects; do not reproduce a source shot.
