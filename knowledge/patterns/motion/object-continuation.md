# Object continuation

- Pattern ID: `PAT-MOTION-001`
- Problem: cuts make a multi-step workflow feel fragmented.
- Mechanism: preserve one object, row, cursor, or container across adjacent states.
- Use for: workflows, pipelines, imports, generation, reconciliation.
- Avoid when: continuity implies a false causal relationship.
- Non-copy rule: the continuity principle is reusable; timing curves and signature morphs are not.
