# Как проект использует Claude Pro/Max

Основной режим проекта — включённое использование подписки Claude Pro или Max в Desktop → Code → Local. Отдельный API-ключ для MVP не нужен.

## Что важно различать

- **Лимит Pro/Max** входит в подписку и общий для Claude, Claude Desktop и Claude Code.
- **Usage credits** — отдельное платное продолжение после исчерпания включённого лимита. Оно включается и пополняется только владельцем аккаунта.
- **Console/API** — отдельный биллинг. Если в системе уже задан `ANTHROPIC_API_KEY`, Claude Code может использовать API вместо лимита подписки.

Проект не включает Usage credits, не покупает bundles, не настраивает автопополнение, не добавляет API-ключ и не меняет модель сам. Для первого пилота оставьте платное продолжение выключенным, если хотите работать строго в рамках подписки. Проверяйте фактический режим и остаток в Settings → Usage; внутренний журнал проекта не является счётом Claude.

Если включённый лимит закончился, система сохраняет checkpoint: текущий этап, согласования, версии файлов и следующий шаг. После восстановления лимита работа продолжается с него, без повторного исследования всего проекта.

## Как снижается расход

- на этапе загружается короткий context packet, а не весь проект и вся библиотека;
- по умолчанию создаются два направления;
- новый research ограничен шестью подробными разборами, а scene retrieval — тремя кандидатами на механизм;
- похожие сцены используют один retrieval packet;
- изменение одной сцены не перезапускает стратегию и не пересобирает весь Figma-документ;
- локальный Figma-плагин создаёт узлы детерминированно и не обращается к модели для каждого слоя;
- обычный проход исправлений один, целевых Figma-циклов не больше двух.

Это ограничения процесса, а не жёсткий серверный token cap. Нельзя честно обещать фиксированное число проектов на Pro/Max: расход зависит от модели, длины контекста, изображений, поиска, сложности и других активных задач аккаунта. Если Claude не сообщает число токенов, журнал сохраняет `null`, а не придуманную оценку.
