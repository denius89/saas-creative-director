# Первый реальный проект

1. Создайте копию папки проекта или скачайте свежий ZIP с GitHub.
2. Положите сайт, PDF, бриф, заметки, скриншоты и другие материалы клиента в `INBOX`.
3. Откройте папку в Claude Code.
4. Напишите: `Начни новый проект для «Название клиента». Материалы лежат в INBOX. Веди меня по шагам на русском языке.`

Claude создаст отдельную папку внутри `projects/`, разберёт входные материалы и сначала покажет, что подтверждено источниками, а что пока является гипотезой.

В процессе будет три понятных согласования:

1. стратегия ролика;
2. креативное и визуальное направление;
3. готовность storyboard и Figma-wireframes к передаче в производство.

Можно отвечать обычными фразами: `Стратегию подтверждаю`, `Выбираю направление 2`, `Вернись на шаг назад` или `Покажи, какие утверждения пока не доказаны`.

Система не создаёт финальный ролик и не копирует стиль выбранной студии. Её результат — проверенная креативная логика и редактируемая препродакшен-база.
