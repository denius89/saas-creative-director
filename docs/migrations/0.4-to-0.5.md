# Migration: 0.4.x to 0.5.0

V0.5 introduces the protected-data boundary and safe updater.

1. Back up the repository.
2. Move private client work into `projects/<project>/`.
3. Move skill customizations out of skill files and into `overrides/<skill-name>.md`.
4. Move reusable private knowledge into `knowledge/custom/`.
5. Put local settings into `config/local.json`.
6. Run `./scd install`, then `./scd health-check`.

Project schema `0.5` is the first supported persisted schema. Earlier unstructured artifacts are not rewritten automatically; copy relevant content into a newly initialized project and retain the original as an archive.
