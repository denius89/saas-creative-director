# Переход с 0.5 на 0.6

Миграция пользовательских данных не требуется.

Версия 0.6 добавляет русскоязычный нетехнический запуск, папку `INBOX`, главный Claude Skill и готовую сборку Figma-плагина. Формат существующих проектов 0.5 остаётся совместимым.

Перед обновлением система создаёт резервную копию обновляемой части. Папки `projects/`, `config/`, `overrides/` и `knowledge/custom/` не заменяются.

После обновления попросите Claude: `Проверь здоровье SaaS Creative Director и объясни результат по-русски.`
