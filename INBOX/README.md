# INBOX

Перетащите сюда материалы нового клиента: brief, PDF, текст, скриншоты, экспортированные кадры, ссылки или заметки.

Затем откройте проект в Claude Code и напишите:

> Начни новый проект для «Название клиента». Материалы лежат в INBOX. Веди меня по шагам на русском языке.

Файлы из этой папки не публикуются в Git благодаря `.gitignore`.
