Research date: 2026-09-27. Scope: first-party page text and studio-owned portfolio profiles. No videos were played; no timecoded visual observations are claimed. Portfolio listing is discovery evidence, not scene annotation. Dates of individual studio projects remain unverified unless subsequently established from original release posts.

[Jigcar case](https://www.anywaystudio.com/case-studies/jigcar): studio reports two treatments derived from the brand guide, client selection of bold typography, interface simplification/enlargement for video, design sources plus live demo, relevant dummy data and client signoff. Dark mode and 2D/3D were deliberate choices. This is a counterexample to universal bans on dark UI, typography, or 3D. Candidate grammar: product-specific selective disclosure; frame hierarchy adapted to viewing time; brand-constrained treatment alternatives. Duration shown as 60 seconds, production five weeks. Outcome statements are testimonial/marketing, not controlled evidence. No project release date established.

[Liveflow case](https://www.anywaystudio.com/case-studies/lifeflow): studio reports using a brand refresh to inform an airy glass-inspired treatment, rebuilding charts in Figma for recognizable UI and legibility, and animating data transformation. Grammar inference: preserve product semantic identity while amplifying a small number of meaningful data states. Glass effects are not intrinsically an anti-pattern. Reported duration 1m37s and production five weeks. Original upload date unverified; cannot label this a 2026 trend example solely from current availability.

## Diagnosis (hypotheses to test on actual failed boards)
1. A script names what is said; it does not specify focal hierarchy, semantic product states, viewing-time legibility, composition or transitions. A model fills that gap with common template motifs.
2. Reference selection at whole-video/moodboard level loses the exact communicative function of a scene. Surface imitation can replace causal storytelling.
3. No approved style-frame bridge means a weak default composition spreads across every scene.
4. UI fidelity versus selective simplification is unspecified: either illegibly dense screenshots or generic invented dashboard cards result.
5. Static frames hide timing and continuity problems. A board needs entry/hold/exit states, focal path, transition anchor, tempo and sound intent even when no video is rendered.
6. Evaluating “modern” in isolation rewards fashionable decoration; evaluate product specificity, visual coherence, intelligibility, distinctiveness and handoff feasibility alongside contemporaneity.
7. A freshness label attached to a URL is not release evidence. Current accessible portfolio does not mean a project was released in 2025/26.

## Candidate visual grammar (proposed taxonomy, not measured prevalence)
- Product proof: real UI / faithfully reconstructed / selectively abstracted / conceptual; specify semantic truth preserved and modifications disclosed.
- Attention: contextual overview → focused detail → state change → consequence; purposeful scale changes; quiet hold after dense action.
- Composition: asymmetric editorial, anchored UI crop, full-bleed product, split comparison, media grid, staged data transformation, purposeful negative space.
- Temporal: match/anchor continuity, object persistence, UI-to-outcome transformation, rhythmic text interstitial, before/after reveal, hold/release contrast.
- Brand: typography roles, color/material policy, density envelope, depth policy, illustration/footage/3D roles.
- Context: feed teaser / landing explainer / founder launch / demo walkthrough / conference film. These impose different pace and legibility constraints.

## Conditional anti-patterns, not aesthetic bans
Record trigger + evidence + exception + repair:
- Repeated centered floating card: flag when consecutive scenes repeat focal structure without semantic reason; allow stable teaching steps; repair with justified attention-scale changes.
- Decorative orbiting UI: flag unsupported or unrelated fragments; allow genuine concurrency/integration relationship; repair with causal workflow states.
- Gradient/glass/3D embellishment: flag only when it obscures product, contradicts brand or exceeds production budget; allow meaningful material/depth or established identity.
- Constant maximum speed: flag insufficient reading/action hold; allow brief teaser impact beats; repair with density-weighted pacing.
- Generic dashboard: flag invented controls/data or vague benefits; allow explicitly labeled conceptual UI; repair with approved product state and relevant data.
- Arbitrary transition: flag no narrative, spatial, brand or rhythmic rationale; allow intentional rupture; repair via persistent object or state-change anchor.
- Style borrowing: flag near-identical branded layout/material/typography combination from one reference; repair by abstracting purpose and combining independent principles within client constraints.

## Curation and plan implications
Add an explicit approved direction/style-frame gate before full board expansion. Have two distinct treatment hypotheses, approve one on 2–3 representative frames, then generate scene contracts. A reference record must distinguish discovered/page-described/frame-viewed/clip-viewed; only clip-viewed records can support timing/transition claims. Store source, studio, client, canonical release evidence, first_seen, last_checked, analyst, observation method, time range, rights/retention status, evidence level and caveat. Date-null items remain usable as craft references but not current-trend support. Prioritize a stratified manually annotated pilot across these four studios, different formats/industries/styles; add historical high-quality controls so “old” is not defined as “bad.” No popularity/view metric should enter aesthetic quality ranking as causal evidence.
