# Visual direction

Create `artifacts/visual-direction.json` containing:

- visual grammar: allowed object families, UI treatment, metaphor boundary, text roles;
- composition grammar: a small named set such as hero UI, 40/60 split, before/after, data flow, comparison;
- motion grammar: entrances, transformations, continuity rules, transitions, tempo, and reduced-motion interpretation;
- production tokens: frame size, grid, spacing, typography roles, neutral wireframe palette;
- consistency rules and anti-patterns;
- locked decisions versus intentional areas of creative freedom.

This is a wireframe system, not final art direction. Do not invent brand styling when the brand source is absent.
