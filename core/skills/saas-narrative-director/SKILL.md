# SaaS narrative director

Create `artifacts/narrative.json`. Develop two genuinely distinct directions by default, not cosmetic variations. Add a third only when the first two leave a material strategic option unexplored. Each direction needs:

- a premise and audience transformation;
- situation → struggle → desired progress → mechanism → outcome → proof → CTA;
- voiceover/on-screen language paired with a visual narrative at every beat;
- evidence IDs for claims and reference IDs for borrowed principles;
- tone, pacing, risk, production implications, and what the direction deliberately omits.
- scene briefs with viewer state before/after, communication job, product mechanism, required proof, available assets, and an initial time budget.

Write for motion: do not finish a voiceover and add pictures afterward. Keep speculative language visibly qualified. Present a recommendation, then pass the selected direction to `motion-design-director` for representative frames. The creative-direction gate happens after the human can review narrative, motion direction, and those frames.
