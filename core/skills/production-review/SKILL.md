# Production review

Validate the project against core schemas and use `evals/rubric.md`; run the CLI validator only when already available. Inspect the actual Figma frames when available. Create `reviews/production-review.md` with blocking issues, important issues, optional polish, and a pass/fail per rubric dimension.

Reject the handoff if any external claim lacks evidence, hypotheses read as facts, frame timing disagrees with the storyboard, important layers are flattened/uneditable, or the illustrator cannot distinguish locked decisions from creative freedom.

Check the actual approved storyboard revision and Figma readback, not only file presence. Verify that the designer can edit a headline, replace a product asset, modify one state, find source/transition notes, and identify locked versus free decisions without reconstructing the scene. Treat static boards as evidence of motion intent only; they do not prove easing, synchronization, or final animation feel.

Do not fix strategic or creative choices silently. Route them back to the relevant stage. If all blocking checks pass, request production approval and stop.
