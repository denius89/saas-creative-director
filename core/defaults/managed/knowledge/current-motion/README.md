# Current motion knowledge

This directory stores dated synthesis, not timeless rules. A record must identify its scope, sources, inspection method, confidence, observation date, and review date. Stale records remain historical context and cannot be presented as current without review.

Use `supported` only when inspected evidence supports the specific statement. Use `hypothesis` for a plausible synthesis with incomplete coverage. Do not infer motion, pacing, or transitions from a title, thumbnail, or portfolio description.

An update to this directory does not modify approved projects. Each approved project pins the knowledge and pattern versions used for its direction.
