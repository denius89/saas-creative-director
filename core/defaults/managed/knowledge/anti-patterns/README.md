# Anti-pattern library

Anti-patterns are conditional detectors, not a blacklist of visual devices. Each record defines a visible trigger, communication risk, repair, allowed exception, and severity. Visual QA may flag an item only when its trigger is observed in the rendered scene or validated handoff.

An intentional exception must name the scene, reason, approver, and approved revision. Never reject a treatment merely because it uses gradients, cards, kinetic type, 3D, or another currently common device.
