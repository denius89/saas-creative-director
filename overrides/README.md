# Skill overrides

Do not edit `core/skills/*/SKILL.md`. Put local behavior in a file named after the skill, for example `overrides/saas-video-strategist.md`.

Overrides may add brand vocabulary, preferred deliverable conventions, review rules, or organization-specific defaults. They may not weaken evidence requirements, remove approval gates, authorize external side effects, or change the product boundary against final-video generation.

This directory is excluded from core updates. Override files are ignored by Git by default because they may contain private operating knowledge.
