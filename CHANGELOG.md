## [0.5.0] - 2026-09-26

### Added

- Protected install/update architecture with `core/`, `config/`, `overrides/`, `knowledge/custom/`, and `projects/`.
- One-command install, GitHub Release update, compatibility checks, backup, rollback, and health check.
- Claude skill adapters that compose immutable core instructions with user overrides.
- Deterministic orchestrator, evidence validation, Figma manifest generation, eval rubric, example project, and tests.
- Installation, upgrading, migration, architecture, and onboarding documentation.
- Mandatory four-tier Reference Research Layer, curated studio seeds, separate reference/pattern libraries, provenance policy, and a 24-work benchmark with eight provisional manual annotations.

### Product milestones included

- V0.1: repository foundation, project model, intake, and product intelligence.
- V0.2: evidence model, competitor intelligence, and video strategy.
- V0.3: reference intelligence, narrative, and approval gates.
- V0.4: visual grammar, storyboard composition, and Figma scaffold.
- V0.5: production review, evals, example, onboarding, and lifecycle management.
